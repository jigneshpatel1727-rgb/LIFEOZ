# iamyansi

`iamyansi` is the embedded intelligence layer of Allinmyday. It is not a separate app and not a sixth core.

## Rules
- Ambient by default; user remains in control.
- Permission-controlled inputs and actions.
- No autonomous code changes or self-deployment.
- Core capabilities are routed through explicit Allinmyday action contracts.
- Sensitive actions require confirmation.
- Web/network access, when introduced, must be explicitly permissioned and transparent.
- Implementation must not add third-party runtime libraries.

## Core responsibilities
1. Understand permitted user input.
2. Normalize information into Allinmyday records.
3. Categorize records into the five core domains.
4. Produce concise status and insight messages.
5. Request confirmation before sensitive actions.
6. Maintain a local, auditable action history.

## Product identity
Brand: Allinmyday
AI: iamyansi
Experience principle: One screen. One tap. One report.
