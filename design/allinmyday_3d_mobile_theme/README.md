# ALLINMYDAY 3D Mobile Theme

This is the standalone visual-theme project, separate from the LifeOS APK and 3D website.

## Target
A realtime 3D-graphics mobile theme consisting of:
- lock-screen visual
- home-screen visual
- original 3D icon language
- 3D widgets
- charging visual
- ambient/AOD visual where device support permits
- six original color variants
- touch/parallax motion specifications

## ALLINMYDAY rules
- Original ALLINMYDAY design only.
- No copied theme, template, icon pack, wallpaper or visual asset.
- No Three.js.
- No CDN.
- No external runtime dependency for the theme preview.
- Theme assets must remain independent from the LifeOS APK build until integration is explicitly tested.

## Current milestone
M1: theme system specification + native realtime preview foundation.

## Android limitation
A normal downloadable theme cannot universally replace every Android system UI element. Wallpaper, icons, widgets, launcher behavior, lock/AOD and charging visuals depend on the device/launcher/manufacturer. This project therefore separates universal visual assets from device-specific integrations.
