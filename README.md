# Allinmyday

Allinmyday is the personal life-intelligence product. **iamyansi** is the embedded AI intelligence/agent — not a separate app and not a sixth core.

## Native application migration

The active Android trial is being rebuilt as a native Android application. Flutter and added Dart runtime packages are no longer part of the active APK build path.

### Dependency policy — locked
- No third-party runtime packages in the Allinmyday APK.
- No Three.js or other 3D framework.
- No CDN-hosted runtime code or external visual assets.
- No copied UI, icon, logo or theme design.
- Realtime graphics are implemented with Android platform graphics APIs/native code.
- External build infrastructure is treated separately from the shipped application and must not become an APK runtime dependency.

## MASTER VISUAL REFERENCE — LOCKED

The user-supplied design board remains the visual source of truth for the product and must be treated as a master layout, not optional inspiration.

### Home experience
- Central iamyansi living intelligence.
- Five unique intelligence symbols/capabilities.
- No permanent core names on the home surface unless context requires them.
- Energy/depth paths connect the intelligence environment.
- Dimensional depth, particles, rings and realtime movement where appropriate.
- Minimal interface: one screen, one tap, one report.

### Product architecture
- Allinmyday is the product.
- iamyansi is the embedded AI intelligence/agent.
- The five cores are structured capabilities, not separate AI agents.
- Voice, memory, reasoning, permissions and verification belong to the iamyansi intelligence layer.
- iamyansi remains an ambient/ghost presence unless the user activates it.

### 3D direction
The mobile 3D theme should feel like the user is inside a world, not looking at a flat wallpaper. Worlds may use different materials, lighting and colour systems rather than repeating a single neon palette.

### Trial rule
A feature is not called complete merely because source code exists. The APK must compile, install and pass the relevant trail checks before it is marked GREEN.
