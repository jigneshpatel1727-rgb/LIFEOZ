# LIFEOZ MASTER DESIGN — LOCKED

This document is the visual implementation authority for LifeOZ/Yansi. The supplied master reference image is the source of truth. It is NOT a screen image to be displayed inside the app.

## Non-negotiable visual target

Recreate the supplied reference as a live, interactive 3D-style environment:

- Deep cosmic/black background with subtle blue atmospheric depth.
- Central Yansi intelligence form: luminous blue/gold organic infinity-like 3D form, bright inner core, energy rings, particles, depth and continuous motion.
- Five distinctive intelligence symbols around Yansi in the same visual language and relative arrangement as the reference.
- No core names on the home screen. Symbols communicate meaning visually.
- Each symbol is a real interactive control, not decoration.
- Energy paths visually connect the five cores to Yansi.
- Motion must be continuous but elegant: orbiting particles, breathing glow, rotating energy structures and subtle depth/parallax.
- User drag/touch can influence the Yansi viewpoint/rotation.

## Functional requirement

Every visual element that represents a feature must eventually be functional. The six realities are selectable environments, not a gallery of static pictures. Holographic Control is an interactive radial control system. The five intelligence symbols open real LifeOS core functions. Yansi is an ambient AI agent and must remain available across the experience.

## AI requirement

Yansi must be integrated into the five cores and should support voice interaction, understanding, categorization, memory, analysis, reminders and actions subject to permissions and confirmation for sensitive actions.

## Engineering rule

Never replace this design with a generic dashboard, five simple circles, a static collage, or a conventional chatbot screen. Build incrementally on the last green APK baseline. Every major change must remain compile-safe before the next visual/AI layer is added.
